# 13 SWOT 与 TOWS：对候选方案做战略态势评估

当 TRIZ 产出若干候选方案后，下一步不是直接执行，而是问：**这些方案在战略上站不站得住？** TRINNO 以 **SWOT**（及其进阶 **TOWS**）在交付前对方案作内外部、正反双向的态势评估。

## 一、SWOT 四维

SWOT 从两个轴向切分：

- **内部 / 正面**：**S**trengths 优势（方案自身强项）；
- **内部 / 负面**：**W**eaknesses 劣势（方案自身短板）；
- **外部 / 正面**：**O**pportunities 机会（环境带来的利好）；
- **外部 / 负面**：**T**hreats 威胁（环境带来的风险）。

其价值在于**对称收敛**：把散落的多维定性判断，压缩进一个 2×2 矩阵，使"该不该做、优先级如何"的争论有共同语言。

## 二、TOWS：从"描述"到"策略"

经典 SWOT 偏重**诊断**（我们处于什么态势）。**TOWS** 则把外部因素作为出发点，反向推导策略组合：

- **SO 策略**：用优势抓机会；
- **WO 策略**：借机会补劣势；
- **ST 策略**：用优势抗威胁；
- **WT 策略**：规避劣势与威胁（防御/退出）。

TOWS 让 SWOT 从"分析报表"升级为"行动菜单"，直接衔接方案取舍与路线规划。

## 三、在 TRINNO 链路中的位置

SWOT 处于解法链路的**评估段**，承接 TRIZ 的候选方案（第 8–11 期），并为最终交付（05_Deliver）与专利（07_Patent）提供战略筛选依据：

```
TRIZ 候选方案  →  SWOT/TOWS 战略评估  →  筛选后的优先方案
```

结合方法论路由：

| 问题类型 | 路由 |
|---|---|
| 战略 / 竞争分析 | **SWOT + PEST** |

SWOT 看"方案自身与近场环境"，PEST（第 14 期）看"宏观与远场环境"，二者常组合。

## 四、与实证闭环的关系

SWOT 的判断不应悬空。TRINNO 强调**不臆测**——SWOT 中的机会/威胁应尽量由 `06_References` 的实证文献与 `01_Discover` 的检索结果支撑，使战略评估同样有据可依。

## 五、小结

SWOT/TOWS 把"方案好不好"从直觉升维为可讨论、可决策的战略矩阵。下一期看更外圈的约束——PEST/PESTEL 宏观环境校验。
