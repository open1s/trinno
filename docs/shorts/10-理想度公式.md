# 10 理想度公式 B/(C+H)：用单一指标逼出最优解

候选方案往往不止一个。如何在不陷入主观争论的前提下，对方案做**可度量、可比较**的择优？TRIZ 的理想度（Ideality）提供了一条简洁而有力的量化公式，TRINNO 以 `/ideality` 将其变为可操作的评分工具。

## 一、理想度公式

```
Ideality = B / (C + H)

B = Benefits   系统产生的全部有益功能（收益）
C = Costs      为维持系统付出的全部成本
H = Harms      系统产生的全部有害作用（危害）
```

公式的直觉是：一个"理想"的系统，应当**用趋近于零的成本与危害，实现趋近于无穷的收益**——即 TRIZ 所说的"理想终态：系统什么都不做，却实现全部功能"。

## 二、/ideality 的输入与输出

```
/ideality benefits: 高转速, 低重量 costs: 制造成本高 harms: 噪声, 发热
```

系统解析收益/成本/危害三要素（支持逗号分隔的多项列举），输出：

- **理想度评分（0–100）**：综合量化；
- **等级（Level）**：如低/中/高；
- **主导因子（dominant）**：当前拉低理想度的主要矛盾；
- **置信度**：评估的把握程度；
- **分项明细表**：各要素得分，便于定位改进靶点。

结果写入 `03_Analyze`（或综合阶段）供后续比对。

## 三、为什么理想度是"逼出最优解"的工具

- **可比性**：把多维度定性判断压缩为单一数值，方案间高下立判；
- **指向性**：主导因子直接告诉工程师"先改哪里收益最大"；
- **演进性**：每轮改进后重算，理想度应单调上升，形成可追踪的优化曲线。

它不是替代工程权衡，而是**把权衡显式化、量化化**，让讨论有据可依。

## 四、在 TRIZ 求解链中的位置

理想度与矛盾矩阵、物场分析同属"分析层"（03_Analyze），常用于：

- 在多个候选方案间做量化排序；
- 评估某次改进的净收益；
- 与 S 曲线（第 7 期）配合，判断"继续改进的空间"。

## 五、小结

理想度公式把"哪个方案更好"从拍脑袋变成可计算的指标。下一期，我们看另一种分析视角——物场（Su-Field）模型如何为系统画一张"关系图"。
