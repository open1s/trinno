# 07 S 曲线与 TRL：给技术做一场成熟度体检

在投入资源求解之前，先要判断：**这项技术到底处在生命周期的哪个位置？** 是尚在萌芽、正处爆发、还是已逼近天花板？TRINNO 用 **S 曲线 + TRL** 双视角回答这个问题，并可叠加 **Gartner 技术炒作周期（Hype Cycle）** 提供市场认知维度的参照。

## 一、S 曲线：性能随投入的增长规律

多数技术的核心性能指标（如能量密度、转换效率）随研发投入呈 **S 形** 演进：

- **萌芽段**：投入大、增益慢，技术原理尚未成熟；
- **成长段**：斜率陡增，性能快速逼近理论极限；
- **饱和段**：曲线走平，边际收益递减，继续投入性价比骤降。

`/s-curve <技术名> <性能指标> [TRL <等级>]` 由 AI 抽取该技术的历史性能数据点，拟合 S 曲线并导出 SVG 图（`02_TRL/s_curve.svg`）与评估文本（`trl_assessment.md`）。

## 二、TRL：技术就绪等级

TRL（Technology Readiness Level，1–9）从"基本原理"到"系统实际验证"刻画技术的工程化成熟度：

```
TRL 1–3  原理/概念/验证（实验室）
TRL 4–6  器件/系统/环境验证（原型）
TRL 7–9  系统原型/运行验证/实战部署
```

用户可显式覆盖 TRL 等级（`TRL 7`），也可由数据推断。TRL 与 S 曲线互为补充：前者看"工程化到了哪一步"，后者看"性能还有多少空间"。

## 三、Hype Cycle 叠加：区分技术成熟度与市场预期

S 曲线描述**客观性能演进**，而 Gartner Hype Cycle 描述**主观预期波动**（技术触发→期望膨胀→幻灭谷底→启蒙爬升→生产力高原）。二者叠加可识别"技术已成熟但预期仍在谷底"或"预期高企但技术尚早"的错配，避免被舆论带偏。

## 四、在方法论路由中的位置

| 问题类型 | 路由 |
|---|---|
| 新技术 / 新市场研判 | **S 曲线 + PEST** |

S 曲线/TRL 回答"技术行不行、到哪了"，PEST 回答"环境让不让你上"——二者常组合使用（第 14 期详述 PEST）。

## 五、小结

成熟度体检是创新决策的地基：避免在饱和技术上重复投入，也不提前押注未熟方案。下一期进入 TRIZ 求解核心——矛盾矩阵与 `/contradiction`。
