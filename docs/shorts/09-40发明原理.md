# 09 40 个发明原理：人类创新经验的"招式库"

矛盾矩阵指向的是"方向"，而真正的**解法灵感**来自 TRIZ 提炼的 **40 个发明原理（Inventive Principles）**。这是一套跨越工程领域、高度抽象的创新"招式库"，TRINNO 以 `/principles` 将其变为随手可查的知识底座。

## 一、原理的本质：跨域可迁移

40 个原理（如分割、抽取、局部质量、不对称、合并、多用性、反向作用、曲面化、动态化、预补偿等）之所以强大，在于它们**不绑定具体行业**——一个来自包装机械的"预先作用"思路，可能同样适用于软件缓存设计。TRIZ 的洞见正是：表面上迥异的发明，底层常复用同一小套"认知动作"。

## 二、/principles 的三种用法

```
/principles list                 # 浏览全部 40 条（名称 + 简述）
/principles <n>                  # 查看第 n 条详述与实例
/principles search <关键词>      # 按关键词打分检索相关原理
```

- **list**：快速建立原理全景；
- **<n>**：深入单条，含定义、适用情境与经典案例；
- **search**：最关键的能力——输入领域关键词，系统做**相关性打分**并返回匹配原理及命中词，把"我该用哪几条"的检索成本降到一次查询。

检索结果写入 `04_Synthesize/principles_applied.md`，与后续方案综合衔接。

## 三、从矛盾到原理再到方案

完整链路为：

```
矛盾矩阵（第 8 期） → 推荐原理编号 → /principles 展开原理 → 映射回本问题的候选方案
```

例如矛盾指向"动态化"与"抽取"，工程师便可在"让结构随工况变形""把有害部分隔离"等方向上发散具体设计。

## 四、与智能体路由的关系

40 原理是 TRIZ 求解链的"知识层"。当问题路由到 TRIZ（技术壁垒类），智能体在矛盾分析后自动衔接原理检索，并在综合阶段（`04_Synthesize`）将其落地为 `solutions.md` 中的候选方案。

## 五、小结

40 原理把"创新"从不可言说的灵感，变成可检索、可组合的方法条目。下一期，我们看如何用**理想度公式**对这些候选方案做量化择优。
